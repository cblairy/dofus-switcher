by Robert Knight and are distributed under the Creative Commons Attribution-ShareAlike 4.0
International license (CC BY-SA 4.0):

- `text-detection.onnx` — https://ocrs-models.s3-accelerate.amazonaws.com/text-detection.onnx
- `text-recognition.onnx` — https://ocrs-models.s3-accelerate.amazonaws.com/text-recognition.onnx
- Model project and training details: https://github.com/robertknight/ocrs-models
- License: https://creativecommons.org/licenses/by-sa/4.0/

SHA-256 checksums for the packaged files:

- `text-detection.onnx`: `a917b23dbd9524b465df7e922641b3ff2981623df4ded5a0234004ef2fee7cfe`

The models are provided separately from the application executable. The project README states
that they are trained on open datasets, including HierText (CC BY-SA 4.0). The model files are
unchanged when included in the application package.
